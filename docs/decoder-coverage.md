# Decoder coverage

Generated by `cargo test --test decoder_coverage` from the checked-in
[row manifest](../crates/shadowbox/tests/data/decoder-rows.tsv) and
[field samples](../crates/shadowbox/tests/data/decoder-samples.tsv).
[Results](../crates/shadowbox/tests/data/decoder-results.tsv) record one
InstructionKind or Unknown for every sample, in manifest order.

Encoding reference: MIT `envytools/envydis/gm107.c:1874-2182`.
Its SHA256 is recorded in both manifests. Every field sample cites its
OP8B row, table, macro and operand definition.

Each selector value (including unassigned values), flag value,
predicate, small immediate/control field (up to 8 bits), and named or
unassigned system register is sampled. Larger data operands use zero,
one, maximum, sign boundary and each single bit; registers use bit
boundaries and RZ. Nested operands select their containing table arm.
Wide selectors that also constrain data operands use each table arm
and each constrained-bit flip. These are one-field-at-a-time probes,
not every combination or every possible operand value.

Decoded means a real IR kind was returned; it does not certify correct
semantics, emitter support, or Vulkan representability. Nop is listed
explicitly and permitted only for Mesa OpNop (`sm50.rs:3178-3184`) or
the scheduling family (`gm107.c:1877-1878`). Reserved means envytools
selects OOPS, not a guess about hardware behaviour. Accepted reserved
probes are reported separately for follow-up. Scheduling control
records and catch-all/assembly dispatch records are included because
they contain OP8B; they are not ordinary instruction rows.

Unknown reasons: **not implemented yet** means this operand, mode or
instruction lacks a decoder representation. **Reserved** means OOPS
in the source table. No row is classified **not representable in
Vulkan** without proof; absent implementation alone is insufficient.
GPU semcheck and Vulkan comparisons were unavailable on the build
server and were skipped. CPU spirv-val validation is separate.

These probes are the widest and weakest check. The stronger ones are
in [decoder-methodology.md](decoder-methodology.md#current-measured-state):
the generated format table was compared with every encoding of 80
rows (all 79 with at most 24 free bits, and one with 28;
1,744,863,232 words), with 0 missing words, 0 wrong admissions and 0
misprints. That historical run did not exercise hand-written decoder
families. A separate real-decoder rerun has completed 53 of the 79
ordinary rows (671,154,176 words) with 0 wrong admissions; VABSDIFF4
has not been rerun. [Wide-row covering sets](decoder-wide-row-validation.md)
are reported as sampled results, never exhaustive closure.
